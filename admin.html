1 · Agregar producto individual (con foto)

La forma más rápida de agregar algo nuevo tú mismo: elige el tipo, llena los datos, sube o pega una foto, y listo. Sirve tanto para cartas Pokémon como para juguetes y coleccionables.

2 · Buscar carta

Escribe el nombre en inglés funciona mejor (ej. "Charizard", "Pikachu"). Puedes agregar varias impresiones distintas de la misma carta.

Con más de ~30 piezas, consigue una llave gratis en dev.pokemontcg.io (botón "Get an API Key", solo pide tu correo) y pégala aquí. Sin ella, "Actualizar todo" va a fallar mucho por exceso de peticiones.

4 · Identificar cartas con IA usando tus propias fotos

Este panel no puede traer una IA integrada sin exponer una llave de pago en el código — cualquiera podría robarla. En su lugar: abre un chat con Claude, sube las fotos de tus cartas y pide algo como "identifica estas cartas Pokémon TCG, dame el precio actual de TCGplayer en MXN y una descripción corta, en formato JSON con los campos name, set, code, num, total, rarity, condition, language, type, kind, price, stock, isNew, image". Claude te devolverá un bloque como el del recuadro de abajo — pégalo aquí y se agrega solo a tu catálogo.

5 · Buscar imágenes en Serebii.net (por set)

Para sets que TCGplayer/pokemontcg.io/TCGdex no tienen (como "Abyss Eye"), Serebii.net sí suele tener galería completa con URLs predecibles por número de carta. Escribe el nombre del set tal como lo tienes guardado y el "slug" que usa Serebii en su URL (lo ves en la barra de direcciones cuando entras a la página del set, ej. serebii.net/card/abysseye/).

Estas imágenes NO quedan bloqueadas automáticamente — revísalas en la tabla antes de cerrarles el candado, por si alguna no cargó bien.

6 · Importar/actualizar desde CSV de Collectr

Sube el export.csv de tu portafolio "ventas" cuando quieras. Compara contra lo que ya tienes (por set + número + nombre) y solo agrega piezas nuevas al catálogo — la imagen no se toca. La rareza siempre se sincroniza con el CSV (útil para corregir cartas mal marcadas como Common que en realidad eran Holo/Reverse Holo). El precio de las que ya existen solo sube, nunca baja: se actualiza al del CSV únicamente si es mayor al que ya tienes (o si tiene candado 🔒, ahí nunca se toca). Si el stock cambió en Collectr, también se actualiza.

7 · Buscar imágenes automáticamente

Busca en pokemontcg.io / TCGdex la imagen real de cada carta suelta sin imagen, y la bloquea 🔒 apenas la confirma (nombre + número + set exactos) — así nunca se vuelve a buscar, aunque corras esto mil veces. Solo tarda en las piezas que de verdad le faltan. Corre en tu navegador, no gasta créditos de ningún plan. Producto sellado y cartas (CN) no se buscan aquí (no hay base de datos confiable para esas).

7b · Sugerir precio de TCGplayer

El precio base de cada carta es el de tu CSV de Collectr. Este botón busca el precio actual de TCGplayer y, solo si es más alto que el que ya tienes, te avisa aquí para que decidas si lo usas — nunca lo cambia solo. De dónde salió cada precio (CSV o TCGplayer) queda guardado para ti en el panel; tu cliente en la tienda nunca ve esa etiqueta.

7c · Reglas de precio estándar

Redondea precios chicos a valores estándar (ej. "todo lo que valga menos de $4 sube a $5"), sin bajar nunca un precio que ya sea más alto que el objetivo de la regla. Agrega, edita o borra reglas cuando quieras — quedan guardadas para la próxima vez.
